## 📌 Sobre o n8n

O **n8n** é uma ferramenta de **automação de workflows open-source**, semelhante ao Zapier, porém com muito mais flexibilidade e controle.

Com ele é possível:

- 🔗 Integrar APIs
- 🗄️ Conectar bancos de dados
- 🤖 Automatizar processos com IA
- 📊 Manipular dados
- ⚡ Criar fluxos complexos com lógica personalizada

Tudo isso utilizando nodes visuais ou código JavaScript.
